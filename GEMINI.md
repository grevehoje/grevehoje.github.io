# GreveHoje Engineering Standards

## Principles
- **Senior Leadership:** Code like a senior/tech lead. Prioritize readability, reliability, and long-term maintainability over cleverness.
- **Modern Best Practices:** Use contemporary patterns (e.g., React Hooks, TypeScript strict mode, ESM) without chasing bleeding-edge instability.
- **No Over-Engineering:** Solve the problem at hand. Avoid abstraction for the sake of abstraction. Build for the current requirements while leaving room for growth.
- **Direct & Simple:** The product is simple, the code should be too.

## Technical Preferences
- **Frontend:** React (TS), Vite, Vanilla CSS.
- **Backend:** Node.js (TS), Express.
- **Style:** Clean, idiomatic code. Follow established patterns in the codebase once they are set.
- **Performance:** Keep bundles small and API responses fast.

## Workflow
- **Validation:** Every feature or fix must be verified.
- **Documentation:** README and code comments should explain "why", not just "what".
